## 演習1：うるう年判定（講師と一緒に・3サイクル＋Refactor）

| 段階 | 追加するテスト | 実行結果 | 実装（Green にする最小のコード） | 保存先 |
|---|---|---|---|---|
| スタート | `西暦2024年はうるう年`（最初から書いてある） | 🔴 1件失敗 | ― | ― |
| サイクル1-a | ― | 🟢 | `return true;`（**仮実装**） | `solved/cycle1a` |
| サイクル1-b | `西暦2023年はうるう年ではない`（assertFalse） | 🔴 → 🟢 | `return year % 4 == 0;` | `solved/cycle1b` |
| サイクル2 | `西暦1900年はうるう年ではない` | 🔴 → 🟢 | `if (year % 100 == 0) return false;` を先頭に追加 | `solved/cycle2` |
| サイクル3 | `西暦2000年はうるう年` | 🔴 → 🟢 | `if (year % 400 == 0) return true;` をさらに先頭に追加 | `solved/cycle3` |
| Refactor | ― | 🟢 のまま | `return (year % 4 == 0 && year % 100 != 0) \|\| year % 400 == 0;` | `solved/refactor` |

### 伝えたいポイント
- **仮実装（`return true;`）は「ズル」ではなく正しい手順。** テストが1つしかない間は、それで十分。
  2つ目のテスト（2023年）が「本当の条件を書け」と要求してくる、という体験をさせる。
- サイクル3で `if` の順番が大事になる（400の判定を100より先に）。順番を間違えると 2000年が赤のまま → テストが教えてくれる。

### 「壊してみる」デモ（Refactor の後に講師が実演）
| 壊し方 | 結果 | 伝えること |
|---|---|---|
| `\|\| year % 400 == 0` を消す | 🔴 `西暦2000年はうるう年` が失敗 | テストがあれば、壊したことにすぐ気づける |
| `400` を `40` に書き間違える | 🟢 **緑のまま！** | テストは「書いたケース」しか守れない。1800年のような「100で割り切れるが400で割り切れない年のうち40で割り切れる年」のテストが無いため。→ **どの値をテストするか選ぶのが大事** → 演習2の「境界値」へ |

（`400`→`40` で緑のままになることは実行して確認済み。1800 のテストを足すと赤になる）

## 演習2：成績判定（自分でテストを考える）

### 仕様
| 点数 | 成績 |
|---|---|
| 90〜100 | A |
| 80〜89 | B |
| 70〜79 | C |
| 60〜69 | D |
| 0〜59 | F |
| 範囲外（マイナス・101以上） | エラー（IllegalArgumentException）※チャレンジ |

### ワークシートの解答例（境界値）
| 入力 | 期待値 | 選んだ理由 |
|---|---|---|
| 100 | A | 上限 |
| 90 | A | A の下端 |
| 89 | B | B の上端 |
| 80 / 79 | B / C | 境目の両側 |
| 70 / 69 | C / D | 境目の両側 |
| 60 / 59 | D / F | 境目の両側 |
| 0 | F | 下限 |
| -1 / 101 | エラー | 範囲外（チャレンジ） |

### よくある誤答と、テストが見つけてくれる例
- `score > 90`（`>=` ではなく `>`）と書く → `点数90はA` が赤になる（検証済み）。
  **「89と90の両方をテストする」意味**をここで実感させる。
- 95点・85点のような「真ん中の値」だけテストしている受講者には、
  「`>=` を `>` に変えても緑のままになるのはなぜ？」と問いかける。

### 実装例
```java
public static String judge(int score) {
    if (score < 0 || score > 100) {
        throw new IllegalArgumentException("点数は0〜100で指定してください: " + score);
    }
    if (score >= 90) return "A";
    if (score >= 80) return "B";
    if (score >= 70) return "C";
    if (score >= 60) return "D";
    return "F";
}
```
（解答プロジェクトでは、初学者の読みやすさを優先して `{ }` を省略せずに書いています）
